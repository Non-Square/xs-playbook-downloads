# XS Playbook Studio downloads

Official public Windows installers and automatic-update metadata for XS Playbook Studio.

- Download the latest installer from [Releases](https://github.com/Non-Square/xs-playbook-downloads/releases/latest).
- Installed applications read `latest.yml` from the latest release and verify the downloaded file hash before installation.
- Application source is maintained separately in a private repository; this repository contains binaries only.

Windows may display a SmartScreen warning for releases marked as unsigned. Production releases will be Authenticode-signed before wider distribution.
